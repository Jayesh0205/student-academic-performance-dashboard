# Viva Preparation

1. **What is the objective?** To summarize student academic records and visualize patterns using a Python dashboard.
2. **Why Python?** It is readable and has mature libraries for data processing and visualization.
3. **What is NumPy?** A Python library for numerical arrays and mathematical operations.
4. **What is Pandas?** A library for tabular data using Series and DataFrames.
5. **What is a DataFrame?** A two-dimensional labeled table with rows and columns.
6. **What is data validation?** Checking that input has the expected structure and valid values.
7. **How is average calculated?** Sum of subject marks divided by the number of subjects.
8. **How is pass percentage calculated?** Number of passing students divided by total students, multiplied by 100.
9. **Why Matplotlib?** It creates charts to communicate patterns visually.
10. **Why Streamlit?** It creates an interactive web app directly from Python.
11. **What is CSV?** A plain-text tabular file format with comma-separated values.
12. **What are limitations?** The prototype has fixed subjects and demonstration grading rules and does not provide authentication or database storage.
13. **Is the sample data real?** No. It is fictional demonstration data.
14. **What would you improve?** Configurable rules, database storage, authentication, more subjects, tests, and deployment.

**Important:** Understand the code and run the project before the viva. Do not claim tests have passed until you have executed them yourself.
